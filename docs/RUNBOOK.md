## Incident: Service Down

**Symptom:** `docker compose ps` shows container as `unhealthy` or `exited`

**Diagnose:**
```bash
docker compose ps
docker compose logs api --tail=50
docker compose logs streamlit --tail=50
```

**Resolve:**

| Root cause | Fix |
|------------|-----|
| Model artifacts missing | `python scripts/run_full_pipeline.py` then `docker compose restart api` |
| Port conflict | `docker compose down && docker compose up -d` |
| Memory limit hit | `docker stats` → increase `mem_limit` in `docker-compose.yml` |
| Image stale | `docker compose build --no-cache && docker compose up -d` |

## Incident: API Latency High (> 100 ms)

**Symptom:** Prediction response time exceeds 100 ms

**Diagnose:**
```bash
curl -w "%{time_total}s\n" -o /dev/null -s \
  -X POST http://localhost:8000/v1/predict/geographic \
  -H "Content-Type: application/json" \
  -d '{"lat":41.85,"lon":-87.65}'
```

**Resolve:**

| Root cause | Fix |
|------------|-----|
| First request after restart (cold cache) | Normal — `lru_cache` loads model once; subsequent calls are fast |
| `kmeans_model.pkl` missing → O(n) fallback | Verify file exists: `ls artifacts/geographic/kmeans_model.pkl` → retrain if missing |
| Container memory pressure | `docker stats` → increase `mem_limit` for api service |

## Incident: Drift Alert Triggered

**Symptom:** `GET /v1/drift/report` returns `overall_drift_detected: true`

**Diagnose:**
```bash
curl -s http://localhost:8000/v1/drift/report | python -m json.tool
```

Check `p_value` for each feature:

| p_value | Action |
|---------|--------|
| 0.01–0.05 | Monitor closely; check upstream data source |
| < 0.01 | Consider retraining |

**Resolve — retrain and reload without downtime:**
```bash
# 1. Retrain (full production pipeline)
FAST_MODE=false python scripts/run_full_pipeline.py

# 2. Reload models without container restart
curl -X POST http://localhost:8000/v1/admin/reload-models \
  -H "X-API-Key: $PATROLIQ_API_KEY"
```

## Incident: Model / Profile Out of Sync

**Symptom:** API returns `500 — Cluster X has no profile`

**Cause:** `kmeans_model.pkl` and `cluster_profile.json` were generated by different
pipeline runs — model predicts a cluster ID that doesn't exist in the profile.

**Resolve:**
```bash
# Full retrain — regenerates both artifacts atomically
FAST_MODE=false python scripts/run_full_pipeline.py

# Then reload
curl -X POST http://localhost:8000/v1/admin/reload-models \
  -H "X-API-Key: $PATROLIQ_API_KEY"
```

---

## Incident: Reference Distribution Missing

**Symptom:** `/v1/drift/report` returns `500 — No reference data found`

**Cause:** `artifacts/reference_distribution.parquet` not generated (pipeline not run or
artifact deleted).

**Resolve:**
```bash
python scripts/run_full_pipeline.py
# run_full_pipeline.py saves the reference snapshot automatically after step 2
```

## Routine: Post-Retrain Checklist

After running `run_full_pipeline.py`:

```bash
# 1. Verify artifacts exist
ls -lh artifacts/geographic/kmeans_model.pkl
ls -lh artifacts/geographic/cluster_profile.json
ls -lh artifacts/reference_distribution.parquet

# 2. Reload API models (zero downtime)
curl -X POST http://localhost:8000/v1/admin/reload-models \
  -H "X-API-Key: $PATROLIQ_API_KEY"

# 3. Smoke test
curl -s -X POST http://localhost:8000/v1/predict/geographic \
  -H "Content-Type: application/json" \
  -d '{"lat":41.85,"lon":-87.65}' | python -m json.tool

# 4. Check drift baseline reset
curl -s http://localhost:8000/v1/drift/report | python -m json.tool
```

## Environment Variables

| Variable | Required | Default | Purpose |
|----------|----------|---------|---------|
| `PATROLIQ_API_KEY` | Yes (for admin) | — | Protects `/v1/admin/*` endpoints |
| `GRAFANA_ADMIN_PASSWORD` | No | `admin` | Grafana login password |
| `ARTIFACTS_DIR` | No | `./artifacts` | Override artifact path in Docker |
| `FAST_MODE` | No | `true` | `false` = full 500K pipeline |
| `LOG_LEVEL` | No | `INFO` | `DEBUG` for verbose output |
